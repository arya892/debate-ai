# DebateAI – Frontend

The client layer for DebateAI, built with **React 18**, **Vite**, **TypeScript**, and **Tailwind CSS**.

---

## Features
- **Clean Editorial Aesthetic:** Warm ivory `#F6F3EA` canvas with deep cobalt blue (`#244DDB`) and vibrant orange (`#FF7043`) dialectic accents.
- **Normal & Readable Typography:** Clean, modern Inter sans-serif typeface across all headlines, body text, and badges.
- **Two-Column Symmetrical Grid:** Side-by-side comparison of **FOR THE MOTION** and **AGAINST THE MOTION**.
- **Real-Time SSE Streaming:** Server-Sent Events showing stage-by-stage generation progress.
- **Teleprompter & Stopwatch:** Practice constructive speeches with a live podium timer and teleprompter font toggles.
- **Single-Click Actions:** Copy individual arguments, copy the complete debate, or download PDF/Markdown.
- **Client-Side State:** Settings remembered automatically in `localStorage`.

---

## Development

```bash
# Install dependencies
npm install

# Run Vite dev server with proxy to backend (port 5173)
npm run dev

# Build for production
npm run build
```
